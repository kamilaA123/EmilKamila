# ⚡ EmilKamila - Умный помощник для выбора энергетика

[![Python](https://img.shields.io/badge/python-3.13+-blue.svg)](https://www.python.org/)
[![PyTelegramBotAPI](https://img.shields.io/badge/PyTelegramBotAPI-4.x-blue)](https://pytba.readthedocs.io/ru/latest/index.html)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

**EmilKamila** — это командный проект, представляющий собой многофункционального Telegram-бота. Бот не только умеет анализировать тональность комментариев с помощью ML-модели, но и дает персональные рекомендации по выбору энергетических напитков, используя нейросеть.

## 🚀 Функциональность

*   **🧠 Анализ комментариев (NLP):** Модель машинного обучения определяет тональность (позитив/негатив) сообщений пользователя.
*   **🤖 Рекомендательная система:** Нейросеть анализирует предпочтения пользователя и предлагает наиболее подходящий энергетик.
*   **💬 Удобный интерфейс:** Простой и интуитивно понятный бот, написанный на `telebot`.

## 🛠 Стек технологий

*   **Язык:** Python
*   **Фреймворк для бота:** PyTelegramApi
*   **ML/NLP:** Transformers Model
*   **Рекомендательные системы:** chat GPT
